# Selected projects · Natalia

A selection of public C# and .NET projects, from a browser game platform to focused desktop and console applications.

| Project | What it explores | Stack |
| --- | --- | --- |
| [PlayGrid](https://github.com/rafalowskaa/BrowserGamesPlatform) | Game publishing, accounts, rankings, moderation and real-time social features | ASP.NET Core, EF Core, SQL Server, SignalR |
| [GamePlatform](https://github.com/rafalowskaa/GamePlatform) | A Windows game platform with a desktop interface and local persistence | WPF, MVVM, SQLite, WebView2 |
| [CountdownApp](https://github.com/rafalowskaa/CountdownApp) | A personalised desktop countdown with images and GIFs | WPF, C#, JSON |
| [HangmanConsoleGame](https://github.com/rafalowskaa/HangmanConsoleGame) | A bilingual console game with local multiplayer and rankings | C#, .NET, NAudio |

Start with **PlayGrid** for the broadest example of application architecture. **CountdownApp** is a smaller project for exploring a focused desktop utility.

Each repository documents its own requirements and current limitations. These projects are presented as learning and portfolio work.
